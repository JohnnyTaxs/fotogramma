# Fotogramma v1.0.4

## Smaller app

- The macOS app bundle drops from about 156 MB to about 106 MB, and the downloaded ZIP from about 64 MB to about 44 MB.
- FFmpeg libraries are no longer shipped twice: each dylib used to be copied both next to the executable and into a second `lib` folder. `deployment/build.py` still verifies the archive and its signature after the change.
- Qt translations, unused Qt plugins, and unused PySide6 modules are no longer packaged. The app keeps its own Italian text and sets its button labels explicitly.

## Fixed conversion dialog

- Fields now fill the available width instead of leaving a large empty gutter, and long option labels no longer push the layout off balance.
- The profile description wraps at full width and is no longer clipped.
- The dialog minimum height is about 700 px, so it fits on smaller laptop screens; it is resizable and has a size grip.
- Buttons and option labels are fully in Italian (including **Annulla**, previously shown as *Cancel*).

## Notes

The macOS archive still uses `ditto`, preserves Qt framework symbolic links, and is ad-hoc signed but not notarized. On macOS 15 and later, allow the first launch in **System Settings → Privacy & Security → Open Anyway**.

Conversion remains local and originals are still replaced only after codec, duration, stream, full-decode, and backup validation.
