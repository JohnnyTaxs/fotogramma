# Fotogramma 2.13.0

## New

- **The results of a conversion in a table.** When more than one file is converted, the progress window has a **Show results** button. It opens a table with every file of the queue: the outcome (converted, replaced, dropped, stopped, error), the size before and after, and the space saved, with the total at the bottom. The columns can be sorted, starting with the biggest saving, and hovering over a row shows the full path, where the new file went and any message. It is there while the queue is still running, and it covers every batch added to the queue, not only the last one. Before, only the last file could be seen in the window.
