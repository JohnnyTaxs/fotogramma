# Fotogramma 2.8.3

## Fixed

- **Updating on Windows no longer uses a hidden script.** The helper that swaps the program was a `.cmd` file that waited with `ping`, a pattern Windows Defender flags. The update is now done by a copy of Fotogramma itself, with no script and no shell. If the folder cannot be replaced, the installed version is left as it was and the reason is written to `%TEMP%\fotogramma-update.log`.

## Notes

- The update is started by the version you already have, so this fix works from the next update on: if you are on 2.8.2 or earlier on Windows, install this version by hand once.
- The program is still not code-signed, so Windows may show a reputation warning the first time.
