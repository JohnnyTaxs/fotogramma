# Fotogramma 2.8.2

## Fixed

- **The right icon.** The window showed the default icon of the toolkit (a black hexagon) in the Windows taskbar and over the macOS Dock icon. It now shows the Fotogramma icon.
- **Clean icon edges.** The icon had a pale fringe along its rounded edges. It is rebuilt with sharp edges; on macOS it has the usual margin and shadow, like other Dock icons.
- **A shorter name.** The window and the macOS menu bar say just "Fotogramma".

## Notes

- On macOS the Dock may keep showing the old icon for a while after the update; restarting the Dock (`killall Dock`) refreshes it.
- Updating from 2.8.0 or earlier on Windows still needs this version installed by hand once. From 2.8.1 on, updates work by themselves.
