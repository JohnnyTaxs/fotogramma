# Fotogramma 2.6.0

After a conversion, Fotogramma now tells you what happened to your library and how much room you got back.

## New

- **Space saved.** When a conversion ends, the progress window says how much space was freed, in bytes and as a percentage, with the sizes before and after (or "Extra space used" if a result grew). Every finished file shows its own figures, and a line stays in the status bar after you close the window. The size "before" is read before any replacement, so it is right in replace mode too.
- **Done stays done.** A video whose original was replaced moves to the compatible ones with its new size, and the statistics follow while the queue is still running. A video converted into a new file stays in the list, since the original is untouched, but is marked **Already converted** (hover for the output path). *Select all* and *Export* skip it, so it is not converted twice by accident; you can still select it by hand to redo it with other settings. The marks live in memory: a new scan reads the real state again.
- **The "To convert" card and the hint** say how many videos are already done.

## macOS requirement

The macOS package needs **macOS 15 or later**: the bundled FFmpeg and x265 are built for it. The bundle used to declare macOS 11, so an older system would open the app and then fail to load a library. It now declares 15.0 and says so up front.

## Documentation

The README has badges, a Requirements table, a **Known limitations** section (software x265 only on purpose, sequential queue, first video stream, why WebM cannot be replaced, no notarization), the GPL note beside the download, a section on why Fotogramma exists, and how to report issues.

## Also in this line since 2.4.0

2.5.0 added the content type (anime or live action), the default output folder, **Select all**, and fixed the `film` tune, the audio choice with the built-in presets, and the console window on Windows. If you skipped it, you get all of that here.

## Unchanged

The validation chain, the atomic replacement with backup, the updater, and the bundled FFmpeg are the same as 2.5.0. The size budget stays at 45 MB for the application and 18 MB for the ZIP and the DMG.
