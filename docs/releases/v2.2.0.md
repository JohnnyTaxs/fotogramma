# Fotogramma 2.2.0

A settings window, a clearer interface, and a cleaner codebase. No change to the conversion pipeline or to the validation that guards replacements.

## New

- **Settings window.** Open **Impostazioni** from the header to choose which codecs count as already compatible (H.265, AV1, H.264, VP9) and the conversion defaults: replace the original, profile, and container. The home page, the statistics, and the table follow a change at once, without a new scan, and everything is remembered in `settings.toml`. Unreadable files always stay errors, and a conversion is still verified as HEVC before an original is replaced.
- **Logo in the header**, next to the title.

## Interface

- **The folder card spans the whole window.** The path field takes whatever room the buttons leave, instead of stopping short of the right edge.
- **Selected cards and filters are colored.** Each category has its color (all, to convert, compatible, unreadable) and the selected stat card and filter pill are filled with it. Before, only "Da convertire" changed.
- **The scan progress bar no longer jumps.** The counter has a fixed-width box and truncates long names, so the bar keeps its length while file names change.

## Code and repository

- `cargo clippy -D warnings` is clean and runs in CI.
- The conversion dialog was split into a form and an action row.
- New tests for custom-profile FFmpeg arguments, every built-in profile (`-n`, `-map 0`), empty tune/AQ, refused replacement paths, failed validation, and codec re-classification.
- README: icon, refreshed screenshots, and a Settings section.
- Agent skills for Rust best practices and testing are tracked in `.agents/`.

## Unchanged

The presets, the validation chain, the atomic replacement with backup, and the bundled FFmpeg are the same as 2.1.0. The size budget stays at 45 MB for the application and 18 MB for the ZIP.
