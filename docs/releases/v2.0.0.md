# Fotogramma 2.0.0

Fotogramma 2 is a complete native rewrite in Rust with `egui`/`eframe`. The interface, Italian language, conversion presets, and every safety rule are unchanged; the macOS application is now roughly five times smaller.

## Highlights

- **Rust + OpenGL**, no Python, Qt, browser, WebView, or HTTP server.
- **22.4 MB** macOS app and **10.0 MB** ZIP, down from 106 MB and 44 MB in 1.0.4. Linux is 40.3 MB / 13.3 MB, Windows 35.4 MB / 11.1 MB.
- **Purpose-built FFmpeg 9.0.2** with only the containers, codecs, filters, and protocols the app uses (GPL, libx265). Linux and Windows build x265 with just the 8-bit and 10-bit paths the presets use.
- Release builds fail if the app exceeds **45 MB** or the ZIP exceeds **18 MB**.
- The same safe behavior: `-map 0`, `-n`, no overwrite by default, HEVC/duration/stream/full-decode validation, and atomic replacement with a backup.

## Interface

- Virtualized table with native sorting, filters, search, and multi-selection.
- Same Cinema Pop theme, embedded Sora and IBM Plex Mono fonts, and original icon.
- Conversion dialog with presets, custom CRF/preset/pixel format/tune/AQ, audio mode, container, and command preview.
- Progress, per-file results, details, open destination, and close confirmation.
- Four visual snapshots cover the main window and conversion dialog at 1280×820 and 1050×680.

## Media handling

- First video stream (`v:0`) only, for `.mp4`, `.mkv`, and `.webm`.
- `hevc` and `av1` are compatible; other readable codecs are convertible; unreadable files are errors.
- Audio and subtitles are copied by default; AAC 128/160/256 kbps is optional.
- MKV output is recommended; MP4 output uses `+faststart`.
- Verified replacement remains limited to MKV and MP4; WebM replacement is rejected.
- Full decode verification now uses the bundled minimal FFmpeg, which includes every decoder needed for copied audio and subtitle tracks.

## Packaging

- macOS ARM: `Fotogramma-Darwin-arm64.zip`; ad-hoc signed and verified after a `ditto` ZIP round-trip.
- Linux x86_64: `Fotogramma-Linux-x86_64.zip`; bundled `ffmpeg`/`ffprobe` and shared objects with an `$ORIGIN/../lib` runpath.
- Windows amd64: `Fotogramma-Windows-amd64.zip`; bundled executables and DLLs.
- Builds are native on each platform and are never cross-compiled.

## Settings

The last directory and window size are written to `settings.toml` under the platform configuration folder. Scan results are never stored.

## Upgrade notes

- The application identifier and icon are unchanged; install the new build in place of 1.x.
- The macOS build is still ad-hoc signed and not notarized. On macOS 15 and later use **System Settings → Privacy & Security → Open Anyway** for the first launch.
- The bundled FFmpeg is GPL v2-or-later because it includes libx265; the build flags are published in `deployment/ffmpeg/`.
- macOS Intel is not built, same as 1.x.

## Verification

- `cargo test --workspace` covers discovery, probing, classification, presets, arguments, allocation, verification, replacement, search, settings, table behavior, and snapshots.
- Two real FFmpeg tests convert a generated clip and exercise atomic replacement, including a byte-identical original in copy mode.
- The moved macOS bundle was started with `PATH=/usr/bin:/bin`, scanned a five-file library, and converted with the bundled tools.
- Fixture parity: two convertible files, two compatible files, one unreadable file.
