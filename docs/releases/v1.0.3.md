# Fotogramma v1.0.3

## Fixed

- **macOS: the downloaded app now starts.** The `v1.0.2` macOS archive was written with a ZIP library that stored the Qt and Python framework symbolic links as full file copies, so macOS killed the app at launch and Finder reported the bundle as damaged. The archive is now created with `ditto`, which preserves the links and the ad-hoc signature.
- **The build proves the archive works.** `deployment/build.py` extracts the published ZIP into a temporary folder and runs `codesign --verify --deep --strict` on both bundles. A broken archive fails the build instead of reaching the release.
- **The bundle reports a real version.** `CFBundleShortVersionString` and `CFBundleVersion` now match the release tag instead of `0.0.0`.
- **Releases publish notes.** Notes live in `docs/releases/<tag>.md`, and the release client updates an existing body when the file changes.

Each package is self-contained: Python, Qt, fonts, `ffmpeg`, and `ffprobe` are included.

## First launch on macOS

The app is ad-hoc signed but not notarized. Extract the ZIP with Finder, right-click `Fotogramma.app` and choose **Open**, then confirm the unidentified-developer warning. On recent macOS versions you can also use **System Settings → Privacy & Security → Open Anyway**.

Do not extract the archive with `unzip`: some tools turn framework symbolic links into copies and the bundle stops working.

## Notes

Fotogramma inspects and converts videos locally. Originals are never overwritten unless you enable verified replacement and every validation step passes.
