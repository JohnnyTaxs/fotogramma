# Fotogramma 2.11.4

## New

- **Time left during the full verification.** When originals are replaced, the decode that checks the converted file before the swap now shows its percentage and about how long it has left ("Full verification · 1 · film.mkv · 42% · about 6 min left"). On a large film on a network share it can take a while, and until now it gave no sign of progress.
- **Stop works during the verification too.** It used to wait for the whole decode to finish; now it stops it at once, removes the converted file and leaves the original untouched.

## Fixed

- **The Maximum profile no longer promises the smallest file.** At the same CRF, the `veryslow` preset keeps more detail and grain, and with AQ mode 3 it gives more bits to dark scenes, so its file can come out larger than High quality's, not smaller. The profile description, the **Which profile to choose?** table and the README now say so: the CRF is what mostly sets the size.
