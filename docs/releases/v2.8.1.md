# Fotogramma 2.8.1

## Fixed

- **MP4 files converted to H.265 now open in QuickTime and Safari.** They were tagged `hev1`, which Apple players refuse; they are now tagged `hvc1`. Files converted with earlier versions can be fixed without re-encoding: `ffmpeg -i in.mp4 -c copy -tag:v hvc1 out.mp4`.

## New

- **Close Window** in the File menu (`Cmd/Ctrl+W`). It asks first when a job is running, like Quit.

## Behind the scenes

- The build workflow is stricter: read-only token by default, actions pinned to a commit, no stored credentials, and the minimal FFmpeg is cached so a build is much faster.
