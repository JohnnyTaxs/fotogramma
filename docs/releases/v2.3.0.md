# Fotogramma 2.3.0

Fotogramma now speaks English as well as Italian.

This release also carries everything from 2.2.0 (the Settings window, the header logo, colored selection, and the clippy cleanup), whose tag was never published as a release.

## New

- **English interface.** Every label, tooltip, dialog, status line, progress message, and error is translated, including the messages produced while converting and verifying files. Numbers follow the language: `1,234.5 MB` in English, `1.234,5 MB` in Italian.
- **Automatic language.** On first launch the app follows the operating system: Italian systems get Italian, everything else gets English.
- **Manual override.** **Settings → Language** lets you choose *Automatic (system)*, *Italiano*, or *English*. The change applies at once and is remembered in `settings.toml`.

## Fixes

- The hint under the table no longer mentions an online search, which was removed in 2.0.1.
- Singular and plural no longer clash ("1 file selezionati"): counts now come after their label.
- The "Already compatible" card is shortened in English so it fits at the minimum window width.

## Under the hood

- New `fotogramma_core::i18n` module with `tr_str` and `tr!`; the application sets the language once and worker threads follow it.
- README screenshots are now in English and show the logo; the README header puts the icon beside the title.
- New tests: language resolution, the language setting round trip, the English UI labels, and English output from the core.

## Unchanged

The conversion pipeline, the validation chain, the atomic replacement with backup, and the bundled FFmpeg are the same as 2.2.0. The size budget stays at 45 MB for the application and 18 MB for the ZIP.
