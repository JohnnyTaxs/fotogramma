# Fotogramma 2.7.0

Safer long conversions, much faster rescans of big libraries, a command line tool, and a font that draws the file names of an anime library.

## Safer conversions

- **Subtitles no longer break MP4.** With MP4 as the target, a file with SRT, ASS or PGS subtitles made `ffmpeg` write nothing and the conversion failed. Such a file now goes into MKV, keeping its subtitles, and the log says so.
- **HDR sources are never flattened.** HDR10 tags, mastering data and light levels were checked and survive the re-encode, but the fast preset would have processed an HDR source in 8 bits. HDR (HDR10 or HLG) is detected at scan time and processed in 10 bits.
- **A minimum saving.** In the conversion dialog and in Settings: when the new file saves less than that percentage, the original is kept and the result dropped.
- **Dates are kept.** A converted file, or a replaced original, keeps the modification date of the original, so a media server that sorts by date does not see the whole library as new.
- **Time left.** The progress line shows a rough time left for the whole queue.
- **The computer stays awake** while a queue runs (macOS `caffeinate`, Linux `systemd-inhibit`, Windows `SetThreadExecutionState`); it can be turned off in Settings.

## A queue you can trust

- **Resume after a crash.** The running queue is saved after every file; if the app or the computer stops, the next start offers to resume what is left.
- **Pause** after the file in progress, and resume.
- **Order**: as listed, largest first (most to gain) or smallest first (quick results).
- **When finished**: do nothing, sleep, or shut down, after a 60-second countdown that can be cancelled.
- **Named presets.** Save the custom profile under a name and pick it from the profile menu.

## Big libraries

- **A scan cache.** A rescan reads only the files that changed (same path, size and modification date), so a library of thousands of files takes seconds the second time. It can be turned off or cleared in Settings.
- **A pool of `ffprobe` threads** (up to 8) that each take the next file, instead of groups that wait for the slowest one.
- **Earlier conversions are recognised.** A video that already has `name.h265.mkv` or `.mp4` in the output folder is marked as converted after a new scan.
- **A Bitrate column** to sort by the files with the most to gain.
- **Export** the list as plain paths, CSV or JSON, chosen by the extension in the save dialog.

## Command line

`fotogramma-cli` ships next to the app: `fotogramma-cli scan /path/to/library` lists what is left to convert with no window, as paths, CSV or JSON, and shares the scan cache with the app. `--fail-if-convert` makes the exit code 1 when something is left, for scripts. See `fotogramma-cli --help`.

## Fonts and file names

- **Outfit replaces Sora** as the interface font. It keeps the geometric look and has arrows and a check mark.
- **Japanese, Chinese and Korean file names** were drawn as empty boxes. A system font for the script is now loaded when a scan finds such names.
- **Release notes** in the update window are rendered (headings, lists, bold, code) instead of shown as raw Markdown.

## Privacy and files

Besides `settings.toml`, two files live in the configuration folder: `scan-cache.json` (path, size, date, codec, resolution and duration of readable videos; switchable and clearable) and `queue.json` (only while a queue runs). Nothing else about your library is stored, and the only network request is still the update check.

## Notes

The macOS package needs macOS 15 or later. The command line tool is part of the app bundle, and the Windows and Linux sleep and shutdown commands, like the Windows swap script, were written and unit tested but not run on those systems.
