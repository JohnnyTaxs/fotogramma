# Fotogramma 2.11.0

## New

- **Files that would grow are stopped early.** After the first 10% of a file the app estimates its final size; if it is clearly heading for a result larger than the original (or than the minimum saving allows) it stops that file after a few minutes, keeps the original and says so in the log, instead of finding out hours later. It is on by default and can be switched off in Settings or in the conversion window.
- **Advice on quality.** The conversion window now suggests a CRF from how compressed the selected files already are (a remux that is already at 5 Mb/s needs a higher CRF than a huge one), with a button to apply it.
- **A clear answer to "Check for Updates…".** A card with a spinner while it checks, then a green check and "You are up to date" or the reason it failed, instead of a faint line at the bottom.
- **A little easter egg.** A chibi girl runs along the progress bar towards a switched-off TV. She never reaches it while the conversion runs; when it has really finished she gets there and the TV turns on. Original pixel art, and it can be switched off in **Settings**.

## Notes

- The size guard looks at the file as it is written, so a file that is on the edge is not stopped: it needs to be clearly too big, with a 10% margin.
- The advice is a rule of thumb based on bits per pixel, not a measurement of your library.
