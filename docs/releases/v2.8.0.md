# Fotogramma 2.8.0

Fotogramma now has a normal application menu.

## New

- **A menu bar like any other app.** On macOS it is the native menu bar: **Fotogramma** (About, Settings, Check for Updates, Services, Hide, Quit), **File**, **Edit**, **View**, **Window** and **Help**. On Windows and Linux the same menus sit at the top of the window.
- **What is in it:** choose a folder, scan, export, convert the selection, select all to convert, clear the selection, search, the four filters, settings, check for updates, About, minimize, zoom and quit, each with a shortcut (`Ctrl` on Windows and Linux, `Cmd` on macOS): `O` choose a folder, `R` scan, `E` export, `Enter` convert the selection, `Shift+A` select all to convert, `Shift+D` clear the selection, `F` search, `1` to `4` the filters, `,` settings, `M` minimize, `Q` quit.
- **Entries are greyed out when they cannot work:** no results yet, nothing selected, a scan running, a window open. While a window is open the menu does nothing underneath it.
- **Quit asks first** when a scan or a conversion is running, like closing the window.
- **An About window:** version, the MIT licence, the GPL note for the bundled FFmpeg and x265, and what is sent over the network (only the update check).

## Notes

- Edit has no Cut, Copy or Paste on purpose: a native item would take Cmd+C and Cmd+V away from the text fields. Those keys keep working there, and macOS adds Dictation and Emoji by itself.
- On Windows and Linux the menu is drawn by the app, not by the system, because a native menu there would need GTK.
- The macOS package needs macOS 15 or later.

## Unchanged

Everything in 2.7.0: the resumable queue, the scan cache, the command line tool, the safer conversions. The size budget stays at 45 MB for the application and 18 MB for the ZIP and the DMG.
