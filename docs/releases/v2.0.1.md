# Fotogramma 2.0.1

Patch release on top of 2.0.0. Three fixes, no new features.

## Changes

- **The online search is gone.** "Cerca H.265 online" opened a 1337x.to search page for the selected title. A public repository that named that site and hardcoded its search URL was an unnecessary policy and takedown surface for a tool that is otherwise self-contained, so the button, the URL builder, and every mention in the README and the docs were removed. The application now opens no browser at all.
- **The Dock icon always shows.** A bundled macOS app takes its icon from `Contents/Resources`, but the bare binary started by `cargo run` fell back to the generic executable icon. The same PNG is applied at startup, so both look identical.
- **The scan row stays inside the window.** The progress bar used to take the whole width, pushing the counter and the **Interrompi** button off-screen and widening the page below. The button is now pinned to the right edge, the bar reserves room for the measured counter, and the counter truncates. A regression test covers the scanning state at 1050, 1280 and 2024 points.

## Unchanged

The conversion presets, the validation chain, the replacement backup, the Italian interface, and the bundled FFmpeg are the same as 2.0.0. The size budget stays at 45 MB for the application and 18 MB for the ZIP.
