# Fotogramma 2.4.0

Fotogramma can now update itself, and macOS gets a proper installer.

## New

- **Self-update.** At startup the app asks GitHub for the latest release. If there is one, a window shows the release notes with **Update and restart**, **Later**, and **Skip this version**. The download is refused unless its SHA-256 matches the `SHA256SUMS.txt` published with the release, and on macOS unless the code signature is valid. The swap happens after the app quits; if it fails, the old version stays in place. A copy started with `cargo run` is never replaced, and the restart waits for a running scan or conversion to end.
- **Updates in Settings.** A switch turns the startup check off and **Check now** checks on demand. `FOTOGRAMMA_NO_UPDATE_CHECK=1` disables it for one run.
- **macOS disk image.** `Fotogramma-Darwin-arm64.dmg` opens on a branded window with the app and an *Applications* shortcut to drag it onto. The ZIP stays in the release: it is what the updater installs.
- **`SHA256SUMS.txt`** is published with every release.

## Privacy

The update check is the first and only network request the app makes: one HTTPS request to `api.github.com` at startup. It reveals your IP address and the app version, like any download, and nothing about your videos or your library. Turn it off in **Settings → Updates**.

## Fixes

- The Settings window scrolls on small screens and keeps its buttons in view.

## Upgrading

2.4.0 is the first version with an updater, and earlier releases publish no checksums: install this one by hand (from the DMG or the ZIP). From here on the app offers the next release itself. The updater is tested on macOS with a real package; the Windows and Linux swap scripts are covered by CI builds but have not been run end to end on those systems.

## Unchanged

The conversion pipeline, the validation chain, the atomic replacement with backup, and the bundled FFmpeg are the same as 2.3.0. The size budget stays at 45 MB for the application and 18 MB for the ZIP and the DMG.
