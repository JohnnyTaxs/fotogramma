# Fotogramma 2.5.0

A content type for the encoder, a default output folder, and three fixes.

## New

- **Content type.** The conversion dialog has a **Content type** menu: *Automatic (from the path)*, *Anime / animation*, or *Films and TV series*. Anime gets `-tune animation`, which keeps flat areas and sharp lines without wasting bits; live action keeps x265's own defaults, which are already made for it. *Automatic* reads the folder names of the path in English and Italian (`Anime`, `Animazione`, `Cartoni`, `Film`, `Serie TV`, `Movies`, `TV Shows`…) and the dialog says what it detected. Anime anywhere in the path wins, so `Anime/Film/` stays anime. A mixed selection is never guessed.
- **Default output folder.** **Settings → Default output folder** chooses where converted files go. Empty keeps the old behaviour: a `Fotogramma-H265` folder next to the originals.
- **Content type in Settings**: automatic, anime, or films and series as the default for new conversions.

## Fixes

- **The "Film" tune is gone.** x265 has no `film` tune, so choosing it in the custom profile made every conversion fail. The valid ones remain: none, animation, grain.
- **The audio choice now applies to every preset.** Original, AAC 128, 160 or 256 kbps was ignored with the built-in presets and only worked with *Custom*.
- **No console window on Windows.** The executable is now a graphical program, and folders open through Explorer directly.

## Unchanged

The validation chain, the atomic replacement with backup, the updater, and the bundled FFmpeg are the same as 2.4.0. The size budget stays at 45 MB for the application and 18 MB for the ZIP and the DMG.

Releases up to 2.3.0 have no updater: if you are on one of them, install 2.4.0 or later by hand once.
