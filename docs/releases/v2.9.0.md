# Fotogramma 2.9.0

## New

- **Updates only if you say so.** The first time you start the app it asks whether it may check GitHub for new versions at startup. Until you answer yes, no network request is made. You can change the answer in **Settings → Updates**, and **Check for Updates…** in the menu always works.
- **A High quality profile.** CRF 20, `slow` preset, AQ mode 3, 10-bit: nearly the same quality as Maximum in about a third of the time (Maximum, with `veryslow`, can take many hours on a long film for 2-3% less space). The conversion dialog now shows the description of the chosen profile above the selector and a **Which profile to choose?** comparison of time, file size and when to use each. The times are indicative.

## Fixed

- **A small window no longer cuts the text off.** The page scrolls when the window is too short, and the table keeps a readable height.
- **The menu bar hover on Windows and Linux** is a faint patch instead of a heavy purple block.

## Notes

- If you had update checks on before, you will be asked once, because the old setting could not tell a choice from a default.
- Updating on Windows uses the helper introduced in 2.8.3 (a copy of the program, no script). It is started by the version you already have, so it is the 2.8.3 helper that applies this update.
