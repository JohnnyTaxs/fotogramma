# Fotogramma 2.12.0

## New

- **Import a list.** **File → Import List…** (`Ctrl/Cmd+I`) opens a list exported earlier, as TXT, CSV or JSON. Its videos are read again with `ffprobe` (the scan cache makes it quick), so the table shows them as they are now; files that are gone show up as unreadable. The command line does the same with `fotogramma-cli scan --from-list <file>`.
- **Leave files out of the scan.** **Settings → Scanning** now has the extensions to scan (MP4, MKV, WebM) and a field for words that leave a file out when its name contains them, such as `NCOP, NCED, trailer`: handy when openings, endings or intros are downloaded next to the episodes. Only the file name counts, not the folders. On the command line: `--exclude-ext webm` and `--exclude NCOP,NCED`.

## Fixed

- **A new scan clears the previous one.** The results of the last library no longer stay on screen (and in reach of Export and Convert) while a new folder is being scanned.
- **The exported file is named in the interface language:** `fotogramma-to-convert.txt` in English.
- **No more `.fotogramma-old` folder after an update on Windows.** When a file of the old copy was still locked (by the program that had just quit, or by an antivirus scan), the update left a `Fotogramma.fotogramma-old` folder behind. The swap now keeps trying for a few seconds, and any leftover folder is removed at the next start.
