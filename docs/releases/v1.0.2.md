# Fotogramma v1.0.2

> **macOS users: use [v1.0.3](https://github.com/JohnnyTaxs/fotogramma/releases/tag/v1.0.3).** The macOS archive in this release was packaged with a ZIP writer that replaced framework symbolic links with file copies. macOS therefore refuses to start the app after download. The Linux and Windows assets are unaffected.

## Included

- Native Qt desktop app for macOS Apple Silicon, Windows x86-64, and Linux x86-64.
- Recursive scan of `.mp4`, `.mkv`, and `.webm` files with HEVC/AV1 detection.
- Conversion presets, command preview, and progress reporting.
- Verified original replacement with atomic backup and full-decode validation.
- Portable builds that bundle Python, Qt, fonts, `ffmpeg`, and `ffprobe`.

## Other fixes since v1.0.1

- Linux builds install the Qt/XCB runtime libraries and a shared `libpython3.11`.
- Windows tests run correctly in CI.
- Release assets upload through the dedicated GitHub `upload_url`.
- The release job sets up Python before invoking the release client.
