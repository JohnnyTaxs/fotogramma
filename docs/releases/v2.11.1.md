# Fotogramma 2.11.1

## Fixed

- **Stopping a conversion is no longer reported as completed.** After **Stop** the window said "Conversion completed", filled the bar to 100% and counted the stopped file as an error. It now says "Conversion stopped" (in the window and in the background bar), the summary does not count the file you stopped as an error, and the bar stays where it was stopped. The mascot stands still and the TV stays off.
